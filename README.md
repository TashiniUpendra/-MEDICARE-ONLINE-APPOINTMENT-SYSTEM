# 🏥 MediCare - Online Appointment System

MediCare is a web-based healthcare management system designed to streamline doctor appointment booking, patient details tracking, and schedule management for patients, doctors, and system administrators.

---

## 🚀 Features

### 👤 Patient Portal
* **Account Registration & Login**: Secure account creation with password hashing.
* **Doctor Search & Filtering**: View available doctors by specialization.
* **Appointment Booking**: Select preferred date and available time slots.
* **Online Payment Integration**: Pay appointment fees securely and view status.

### 👨‍⚕️ Doctor Portal
* **Schedule Management**: Set and update doctor session timing and room numbers.
* **Appointment Tracking**: View assigned patient appointments and status.
* **Payment Verification**: Check and update payment states for patient visits.

### 🛠️ Admin Dashboard
* **Full System Control**: Manage system users (Patients, Doctors, Admins).
* **Doctor Profiles**: Add new doctors with photos, specializations, and details.
* **Database Overview**: Monitor overall appointments and payments.

---

## 🛠️ Tech Stack

* **Frontend**: HTML5, CSS3, JavaScript, Bootstrap 5, Bootstrap Icons
* **Backend**: PHP (Procedural / MySQLi)
* **Database**: MySQL (phpMyAdmin)
* **Server**: XAMPP / WAMP / Localhost
